## 安装

### Termux
```bash
curl -sSL https://raw.githubusercontent.com/Maxx-EX/Maxx/main/maxx-install | bash
```

### Android
下载 APK 直接安装。

## 使用
```bash
maxx                  # 进入 REPL
maxx run main.max     # 运行文件
maxx check main.max   # 检查错误
```
